# IT Assets

IT Asset Management app for Centurisk. Tracks devices, serial numbers, assignments, and lifecycle.

## Features

- Device inventory (laptops, desktops, monitors, etc.)
- Assignment tracking with automatic history logging
- Status lifecycle (Active, Available, In Repair, Retired)
- CSV import for bulk data
- Integrates with Frappe Helpdesk

## Installation

```bash
bench get-app https://github.com/neilcenturisk/it-assets
bench --site YOUR_SITE install-app it_assets
```
